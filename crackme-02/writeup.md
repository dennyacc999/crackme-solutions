# CrackMe 02

## Informasi Challenge
- Nama Challenge : CrackMe 02
- Sumber : crackmes.one
- Tingkat Kesulitan : Easy

## Tujuan
Memahami flow kontrol program dan teknik analisis conditional branch.

## Tools yang Digunakan
- Ghidra
- x64dbg
- Detect It Easy (DIE)

## Langkah Analisis
1. Identifikasi tipe file menggunakan Detect It Easy.
2. Membuka binary di Ghidra untuk analisis dekompilasi.
3. Menelusuri conditional branch (if-else).
4. Mengamati perbandingan input user.
5. Menentukan kondisi untuk valid input.

## Hasil
Program menggunakan conditional statement sederhana untuk memvalidasi input. Dengan memahami branching, logika bypass dapat diketahui.

## Kesimpulan
CrackMe 02 melatih pemahaman terhadap percabangan logika dalam program dan bagaimana input divalidasi melalui kondisi tertentu.
