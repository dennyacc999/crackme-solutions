# crackme-solutions
Writeup and solutions for Reverse Engineering CrackMe challenges.

# CrackMe Solutions

## Deskripsi
Repository ini berisi dokumentasi hasil analisis dan penyelesaian beberapa tantangan CrackMe sebagai bagian dari proses pembelajaran Reverse Engineering.

## Tujuan
- Melatih kemampuan analisis file binary.
- Mempelajari logika program tanpa source code.
- Mendokumentasikan langkah-langkah penyelesaian setiap challenge.

## Isi Repository
Setiap folder berisi satu challenge CrackMe yang dilengkapi dengan writeup, tools yang digunakan, proses analisis, dan hasil yang diperoleh.

Seluruh dokumentasi ditulis dalam Bahasa Indonesia sebagai bagian dari portofolio mata kuliah Reverse Engineering.
