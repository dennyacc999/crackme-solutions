# crackme-solutions

Writeup and solutions for Reverse Engineering CrackMe challenges.

## 📝 Deskripsi
Repository ini berisi dokumentasi hasil analisis dan penyelesaian beberapa tantangan CrackMe sebagai bagian dari proses pembelajaran Reverse Engineering. Seluruh dokumentasi ditulis dalam Bahasa Indonesia sebagai bagian dari portofolio mata kuliah.

## 🎯 Tujuan Pembelajaran
* Melatih kemampuan analisis file binary (PE/ELF).
* Mempelajari dan memahami logika program tanpa access ke source code asli.
* Mendokumentasikan langkah-langkah penyelesaian setiap challenge secara sistematis.

## 📌 Disclaimer
> Semua analisis yang didokumentasikan di sini dilakukan di dalam lingkungan terisolasi (Virtual Machine) yang aman. Repositori ini dibuat murni untuk tujuan akademis, riset, dan pembelajaran keamanan digital.
